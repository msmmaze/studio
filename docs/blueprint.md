# **App Name**: VPN Flow

## Core Features:

- VPN Mode Selection: Toggle switch for bypassing VPN for specified applications, routing only chosen applications through the VPN, and local network bypassing.
- Kill Switch: On/off switch to enable or disable the kill switch functionality, blocking all traffic when the VPN disconnects.
- Import OpenVPN Profile: Option to import OpenVPN profile files.

## Style Guidelines:

- Primary color: Dark blue (#24292F) for a professional look.
- Secondary color: Light gray (#F6F8FA) for backgrounds and subtle contrasts.
- Accent: Teal (#26A69A) for interactive elements and toggles.
- Clean and modern sans-serif font for readability across platforms.
- Simple, flat icons for settings and status indicators.
- Intuitive layout with clear sections for each feature.
- Smooth transitions and animations for toggles and status changes.
